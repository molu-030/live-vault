# 3.11.0-preview / versionCode 34 — 녹음 편집·영상 사본·용량 관리

## 이번 변경

### 원음 보관과 저장 공간

녹음 설정에서 이후 녹음의 **원음 보관**을 선택한다(기본 켜짐). 끄면 최종 믹스만 저장하며 기존 원음은 삭제하지 않는다. 마이크 원음·고정 믹스·처리된 보컬 스테레오를 보관하면 48 kHz에서 최종 믹스 외 약 **58 MB/분**이 추가된다. 최종 PCM16 믹스까지 포함하면 약 69 MB/분이다. 원음은 기기 AEC·소음 처리 이후이므로 제거된 소리를 복구하는 원본이 아니다.

보관함과 녹음 설정에 사용량·기기 여유 공간을 표시한다. 녹음 시작은 현재 설정의 1분 예상 용량과 64 MiB 여유를 요구하며 예약 실행 시 다시 검사한다. 영상과 후편집 사본의 임시 파일·소스 복제도 별도로 추정한다. 추정치는 녹음 가능 시간을 보장하지 않으며 실제 쓰기 오류 때는 기존 파일을 보존한다.

테이크 메뉴의 **이 테이크의 원음만 삭제**는 확인 후 그 테이크의 세 분리 파일만 지운다. 최종 WAV·MP4·MIDI와 독립 소스를 가진 다른 사본은 유지한다. 녹음·예약·영상 저장 중 정리를 막고, 메타데이터 실패 시 임시 이름을 되돌린다. 자동 용량 정리로 원본을 삭제하지 않는다. 사용자가 보관을 끈 경우와 저장에 실패한 경우를 구분해 표시한다.

### 화음·목소리 악기 녹음의 추가 효과

기존 마이크 원음 재처리에 더해, 녹음 당시의 처리된 보컬 버스 전체를 `.vocal.wav` float32 stereo로 보존한다. 실제 부른 목소리·자동 화음·목소리 악기는 이 버스에, 디지털 반주·이미 녹음된 보컬 루프는 고정 믹스에 둔다. 기존 최종 녹음의 라우팅과 싱크 보정은 바꾸지 않는다.

- **마이크 원음 · 효과 재계산**은 기본 보컬 효과를 원음에서 다시 계산한다.
- **녹음된 보컬 · 추가 효과**는 녹음 당시 화음·효과·목소리 악기를 보존한 채 효과를 추가한다. 이미 적용된 화음을 없애거나 다른 화음으로 바꾸지는 않는다.

두 모드는 서로 다른 보관 원음을 사용하며 다른 모드의 편집이나 현재 사본에 효과를 겹쳐 계산하지 않는다. 추가 효과가 중립이면 기존 보컬의 고역 통과 필터를 다시 적용하지 않고 원래 스테레오를 보존한다. 저장 사본은 분리 파일도 독립적으로 복제하므로 원본 삭제와 무관하게 재편집할 수 있다. 이전 버전에 보컬 분리 파일이 없던 녹음에 이를 소급 생성하지 않는다.

오디오 콜백의 5채널 큐와 버퍼는 사전 할당하며 파일 읽기·쓰기와 렌더는 작업 스레드에서 수행한다. 보컬 분리 파일 저장 실패는 최종 믹스와 정상 보관된 다른 소스를 삭제하지 않는다.

### 편집한 소리를 새 영상에 합치기

새 영상 녹음은 카메라와 오디오 사이의 부호 있는 시간 차이를 저장한다. 후편집 화면에서 **WAV 복사본 저장 / MP4 복사본 저장**을 구분한다. MP4는 먼저 편집 WAV와 독립 소스를 저장한 뒤 원래 영상 트랙과 새 AAC 오디오를 결합한다. 원본 영상의 크기·회전·샘플 타임스탬프를 보존하고 이미 WAV에 적용된 녹음 싱크를 중복 적용하지 않는다.

단계별 진행 상태와 취소를 제공한다. 영상 결합 실패·취소에도 이미 저장된 편집 WAV와 원본은 남고 임시 파일만 정리한다. WAV 길이·트랙 수·회전·크기·샘플 수/시간을 검사한 뒤 결과를 게시한다. 오디오 인코더에는 취소 지점과 대기 제한을 둔다.

정확한 카메라 시간 차이가 없는 **과거 영상은 WAV 편집 사본만 지원**한다. 알 수 없는 음수 트리밍을 임의로 추정하지 않는다.

### 개인용 효과 설정 기록

개인용 앱 ID와 Activity 클래스 패키지가 달라 효과 설정 파일명이 달라지는 경우를 수정했다. 서비스가 녹음을 시작할 때 실제 Activity와 같은 설정 파일을 읽으며, 사용자 효과값이 후편집의 초기 설정으로 이어지는지 검사한다.

### 화면 검수

효과 편집의 저장·닫기는 스크롤 본문 밖에 고정한다. 스위치와 주요 버튼은 48dp 이상이며 직전 목소리 복구 안내는 간략히 표시하고 상세 설명을 별도 창으로 옮겼다. 화면 검사는 합성 WAV·보관 시간·프로젝트 버전을 사용하며 음향이나 실제 영상 재생을 증명하지 않는다.

## 검증 범위와 남은 실측

44.1/48 kHz ASAN/UBSAN 실제 엔진 검사에서 화음·신시사이저·SoundFont 목소리 악기·보컬 음소거·마이크 전용·일시정지·±250ms 싱크를 포함한 중립 추가 효과 결과가 원래 WAV와 바이트 단위로 일치했다. 추가 효과가 디지털 반주를 바꾸지 않는 검사, 손상 파일·취소·큐 포화·분리 파일 실패 검사도 포함한다.

Java/UI 최종 고유 테스트 **324개 통과**: 전체 324개 실행에서 후행 공백까지 글자 너비로 판정한 화면 테스트 1건을 수정한 뒤 해당 화면 3개 테스트를 재실행해 모두 통과했다. 1480×924·960×600, 한글/영어, 100%/130% 글씨의 양쪽 효과 모드·고정 WAV/MP4 저장·닫기·직전 목소리·버전 20개를 실제 Android 뷰/Skia로 검사했다.

Java/UI 결과와 렌더·개인용 APK 정보는 `validation/v3.11.0/`에 기록한다. 영상 트랜잭션과 타임라인 규칙의 단위 검사는 실제 Android MediaCodec 하드웨어 검증과 구분한다.

연결된 실기기가 없으므로 **S9 Ultra 실제 스피커 하울링·장치 재연결·입출력 지연·장시간 녹화·배터리와 실제 MediaCodec 영상 결합은 미검증**이다. 역상 출력만으로 방의 반사와 마이크 재유입을 제거할 수 없으며 기존 AEC·단계적 보호를 유지한다. 개인용 APK만 기존 앱 ID/인증서로 전달하고 일반용 APK·서명키·개인 캡처 소스는 공개 커밋에서 제외한다.
