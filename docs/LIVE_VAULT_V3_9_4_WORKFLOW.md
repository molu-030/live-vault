# Live Vault 3.9.4 — 작업 상태와 태블릿 믹서

경쟁 앱 비교에서 우선 제안한 작업 흐름을 기존 매트 LCD 테마에 적용한다. 개인용 `3.9.4-preview / versionCode 31`이며 기존 서명과 앱 ID를 유지한다.

- 작곡기에서 자동 초안과 내 반주 저장을 구분하고, 저장 중·완료 시각·실패·재시도를 지속 표시한다. 프로젝트/저장 요청 세대로 늦은 응답을 거른다. 실행 취소/다시 실행을 상단에 노출하고 이름 있는 프로젝트 복사본을 저장할 수 있다.
- 목소리 기록은 실제 재생 파트 또는 정지 시 선택 파트와 대상 트랙을 표시하며 시작 후 대상을 고정한다. 직전/새 프레이즈 비교는 세션 내 기능이며 다른 편집·전조·프로젝트 이동·재기록 뒤 오래된 선택을 적용하지 않는다.
- 태블릿 라이브의 보컬 효과/트랙 믹서를 전환한다. 최대 8개 실제 트랙에 출처·뮤트·임시 솔로·세로 게인을 표시한다. 채널별 가짜 미터는 없다. 게인은 한 번의 드래그에 한 번 저장하고, 솔로는 화면 이탈 시 해제한다.
- 라이브 상태 영역에는 현재/다음 파트와 마디, 고정 녹음 영역에는 전체 믹스/마이크 전용 대상을 표시한다. 기존 리버브·에코 노브와 독립 반주 음량은 유지한다.
- 화음 성부는 태블릿 2×2, 폰 한 열 타일로 배치한다. 각 타일에서 대기·녹음·저장·재생·뮤트·실패, 기록 대상과 직접 복원을 확인한다. 재녹음은 기존 성부를 교체하는 동작임을 명시한다.
- 오디오 준비는 장치 선택 → 입력 레벨 → 싱크·보호 확인으로 안내한다. 화면 진입으로 마이크를 켜지 않으며, 기존 싱크 검사는 실제 왕복 지연 측정이 아닌 청취 검사라고 표시한다. 보정값은 기존 출력 모드별 공유이며 장치별 프로파일을 새로 구현한 것은 아니다.
- 상세 오디오 설정의 효과 A/B는 리버브·에코·EQ·컴프레서만 비교한다. 음량·마이크·AEC·보호 설정은 바꾸지 않는다. 취소/이탈은 원복하며, 녹음 시작 또는 녹음 중 이탈은 현재 효과를 유지하고 비교를 종료한다.
- 반주는 낮은 강약의 심벌/필인을 덜어내고, 워킹 베이스는 실제 코드 베이스 변경 직전에 반음 접근을 사용한다. 시드 재현과 기록한 프레이즈 데이터/타이밍을 유지한다.
- DSP는 새 스트림에서 아직 비영 입력이 없던 경로만 쉬게 한다. 한번 입력이 들어온 뒤에는 기존 처리를 계속해 잔향과 재개를 보존한다. 전체 지연 버퍼를 검사하는 절전 방식은 호스트에서 콜백 지연이 관측되어 제외했다. 실제 배터리 절감률은 측정하지 않았다.

원음 별도 보존 후 효과 재편집, 직전 구간 복구 버퍼는 이번 구현에 포함하지 않는다. 기존 파일·프로젝트 형식과 녹음 복구를 유지하며 이 두 기능은 별도의 저장·중단 복구 설계가 필요하다.

실제 S9 Ultra/폰의 마이크·스피커·카메라·Bluetooth·지연·배터리 검사는 합성 입력과 Android 뷰 렌더가 대체하지 않는다.

## 최종 검증과 전달

전체 Java/Robolectric 261개 실행에서 258개가 통과했다. 화면 회귀 3건을 수정하고 잘린 글자·그려진 글자·가시 영역 검사를 보강한 뒤, 화면/태블릿/온라인 플레이어/믹서 17개를 모두 통과했다. 클래스별 최신 결과를 교체하면 중복 제외 262개 통과이며, 262개를 한 번에 전체 통과한 실행은 아니다. [실행별 집계](validation/v3.9.4/coverage.json). 저장·이전 요청 차단·테이크 비교·화음 원본 보존·A/B 녹음 안전 검사도 포함한다.

DSP/화음/작곡기/하울링 보호, 9개 그루브·박자별 강약·시드·프레이즈 불변, 엄격 ASan/UBSan과 입력 재개/EQ 상태 보존 검사가 통과했다. 6/8 저에너지 심벌은 큰박 0/1.5, 3/4는 0/1/2를 유지한다. [네이티브 명령·출력·소스 해시](validation/v3.9.4/native.txt).
