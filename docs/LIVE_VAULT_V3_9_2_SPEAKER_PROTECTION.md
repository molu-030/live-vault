`3.9.2-preview / versionCode 29`, 개인용 APK. 구현은 Sol medium, 루트가 신호 경로와 검증 결과를 직접 검수했다. [3.9.1 노브 디자인](LIVE_VAULT_V3_9_1_DESIGN_REVIEW.md)과 [3.9.0 태블릿 배치](LIVE_VAULT_V3_9_0_TABLET.md)를 포함한다.

## 역상 출력과 AEC

단순히 180도 위상을 뒤집은 소리를 스피커로 내보내는 방식은 방의 반사·거리·지연을 따라가지 못한다. 특정 위치에서 줄어도 다른 위치나 주파수에서 커질 수 있으므로 앱 전체 출력에 적용하지 않는다.

이 앱은 지원되는 기기의 Android `AcousticEchoCanceler`를 AAudio 입력 세션에 연결한다. AEC는 스피커 출력이 마이크로 돌아오는 경로를 추정해 마이크 신호의 에코를 줄이는 입력 전처리다. 새 자체 AEC 알고리즘이나 추가 역상 스피커 출력을 구현한 것은 아니다. 제조사의 통신 입력 프리셋 내부 처리와 실제 제거 성능은 별도로 측정해야 한다. 음악 효과인 에코·리버브와도 별개다.

## 확인한 문제와 보강

| 경로 | 이전 문제 / 동작 | 변경 |
|---|---|---|
| 기기 AEC 표시 | 설정이 켜져 있으면 효과가 없거나 활성화에 실패해도 활성으로 보고할 수 있었음 | 현재 입력 세션·효과 객체·제어권·활성화 반환값·실제 활성 상태를 확인. 꺼짐/사용 불가/활성/오류를 구분하고 마이크가 꺼져 있으면 확인 대기로 표시 |
| 효과 수명 | 같은 라우팅 객체에 재연결하거나 마이크만 끌 때 효과가 남을 수 있었음 | 재연결 전 이전 AEC/NS/AGC 해제, 마이크 종료 때 즉시 분리. 서비스 시작·효과 변경·장치 전환·기존 주기에서 상태 갱신 |
| 상승하는 되먹임 톤 | 최대 4개 노치 필터와 반복/과부하 음소거 | 기존 판정에 더해 1차 −4dB, 2차 총 −8dB 모니터 감쇠. 기존 10초 내 3차 반복 판정은 음소거 |
| 감쇠 적용 | 해당 없음 | 약 10ms 시정수로 스테레오 모니터 게인을 부드럽게 변경. 조용해져도 자동 복원하지 않으며 경로 우회·보존 재열기에도 감쇠 유지 |
| 조작과 상태 | 초기/재시작 모니터 18%, 상한 65% | 유지. 사용자가 보호를 해제하거나 새 세션을 시작할 때 추가 감쇠 초기화. LCD와 출력 설정에 보호감쇠를 표시 |

노치와 추가 감쇠·음소거는 **보컬 및 목소리 악기의 모니터 경로**에 적용한다. 반주 게인·시스템 볼륨·기록 이벤트·녹음 파일 쓰기 경로를 변경하지 않는다. 보호가 동작해도 녹음 세션은 계속된다. 기기 AEC 자체는 입력 전처리이므로 녹음 입력의 음색에 영향을 줄 수 있으며 설정에서 끌 수 있다. 자동 입력 게인은 기존 기본 꺼짐을 유지한다.

기기 AEC가 사용 불가/오류 상태여도 노치·감쇠·음소거 보호는 별도로 동작한다. 안전한 개인 청취 장치에서는 보호를 우회하며 다시 스피커로 돌아왔을 때 기존 감쇠와 음소거 이력을 유지한다. 긴급 음소거와 명시적인 18% 재시작도 유지한다. UI는 기존 갱신 주기를 사용하며 추가 반복 타이머를 만들지 않는다.

## 검증

네이티브 44.1/48kHz 합성 검사는 다음을 확인했다.

- 250/400/1500/6000Hz 성장 톤, 반복 상승, 과부하·비정상 값, 스테레오 음소거와 복구
- 노치 주파수와 떨어진 왼쪽 730Hz/오른쪽 2700Hz의 실제 에너지로 −4/−8dB 광대역 감쇠 확인
- 첫 감쇠가 즉시 큰 레벨 점프로 적용되지 않음, 무음 후 유지, 이어폰 우회·스피커 복귀·재열기·명시적 초기화
- 조용한 톤·안정된 톤·배음/비브라토 발성·잡음·단발 과도 입력에서 불필요한 감쇠가 생기지 않음

[피드백 검사](validation/v3.9.2/feedback-native.txt), [ASan/UBSan 검사](validation/v3.9.2/feedback-sanitized.txt), [기존 DSP·입력·녹음 관련 호스트 검사](validation/v3.9.2/audio-native.txt)가 통과했다. 새 JNI 함수가 세 ABI의 실제 APK 라이브러리에 존재하는 것도 확인했다.
