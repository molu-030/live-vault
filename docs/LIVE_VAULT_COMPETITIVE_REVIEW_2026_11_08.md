# Live Vault 경쟁 앱 비교와 개선 제안

후속 구현: [3.9.4 작업 흐름 개선](LIVE_VAULT_V3_9_4_WORKFLOW.md), [3.10.0 녹음 후편집·복구·프로젝트 버전](LIVE_VAULT_V3_10_0_RECORDING_WORKFLOW.md), [3.11.0 화음·영상 편집·용량 관리](LIVE_VAULT_V3_11_0_EDIT_STORAGE.md). 아래는 검토 당시 제안이며, 실제 구현 범위·제약·검증은 후속 문서에서 구분한다.

검토일: 2026-11-08. 현재 소스와 Galaxy Tab S9 Ultra 비율의 기존 Android 뷰 렌더를 공식 매뉴얼·도움말·제품 화면과 비교했다. 경쟁 앱을 기기에 설치해 성능이나 사용성을 실측한 결과는 아니다. GarageBand·Loopy Pro의 iPad 기능은 사용 흐름을 참고하며, Android에서 같은 오디오 기술이나 지연을 보장하지 않는다.

## 판단

Live Vault는 기능 수보다 **현재 작업과 상태의 가시성**을 먼저 개선해야 한다. 자동 반주, 목소리 악기, 프레이즈 기록, 자동 화음, 실제 목소리 레이어가 이미 있지만 서로 다른 화면과 녹음 동작을 사용한다. 사용자가 “무엇이 재생되고, 무엇을 녹음하며, 어디에 저장되는지”를 바로 알게 만드는 것이 우선이다.

승인된 매트한 어두운 테마·라임 LCD·모서리가 둥근 사각 버튼·큰 노브는 유지한다. 다만 태블릿 렌더에서는 LCD와 두 노브가 넓은 공간을 차지하는 반면 트랙·파트·저장 상태는 다른 화면에 있다. 라이브용 조작은 간결하게 두고, 필요할 때 같은 자리에서 믹서와 작업 정보를 보는 방향을 권한다. 전체 재디자인이나 경쟁 앱의 시각 자산 복제를 제안하는 것은 아니다.

| Loopy Pro | 클립의 녹음·재생·겹쳐 녹음과 박자에 맞춘 시작을 중심으로 구성한다. 입력과 효과 경로를 나누고, 비활성 효과의 DSP 절전을 다룬다. [공식 매뉴얼](https://loopypro.com/manual/) | 현재 화음 화면에 이미 있는 카운트인·대기·녹음·복구 기능을 4개 성부 타일 안에 모은다. 긴 목록과 메뉴 이동을 줄이고 상태·레벨·남은 박을 각 성부에서 확인한다. |

위 표의 오른쪽 열과 아래 항목은 자료를 바탕으로 한 Live Vault용 제안이다. 경쟁 앱이 동일한 해결책을 사용한다는 뜻은 아니다. Apple 일부 문서는 검색에 제공된 공식 문서 본문을 확인했으며 해당 앱의 최신 화면을 직접 실행하지 않았다. Voloco 화면은 배포 중인 공식 PDF의 예시다.

## 현재 구현과 제안의 구분

- **이미 있음:** 버전 JSON·자동 초안·저장/복제/이름 변경/삭제, 실행 취소/다시 실행 20단계, 파트별 강약/휴머나이즈/필인, 9개 리듬과 악기 패턴, 생성/건반/목소리 기록, 화음 4성부의 녹음 대기·취소·이전 성부 복원·뮤트·볼륨/팬, 고정 하단 조작부, 실제 IN/OUT 미터, 리버브/에코 메인 노브, 장치/버퍼/싱크 설정.
- **개선 필요:** 작곡기 저장 성공의 상시 표시, 트랙의 생성 방식 구분, 전체 믹스 녹음과 프레이즈/성부 기록의 관계, 태블릿에서의 8트랙 동시 조작, 화음 성부별 진행 상태의 집중 표시. 라이브의 기존 준비/저장 중 표시와 종료 토스트는 유지하되 완료·실패 결과를 더 오래 확인하게 한다.
- **이 문서에서만 제안:** 믹서 보기, 저장 상태 배지·이름 있는 로컬 스냅샷, 장치별 설정 안내, 효과 A/B, 음악적 편곡 제안, 독립 테이크 선택, 원음 보존 기반 재편집, DSP 절전 확대. 이번 APK에 모두 구현했다고 해석하면 안 된다.

## 우선순위와 구체적인 수정안

| 순서 | 수정안 | UI/기능과 검증 기준 |
|---|---|---|
| P0 | 저장·재생·편집 오류 해결 | 영상 원본 손실, 내보내기 복원, 리듬 인덱스, 입력 샘플 처리, 프레이즈 호환 문제를 먼저 해결한다. 이번 3.9.3 검수 수정과 검증은 별도 문서에 기록한다. |
| P1-1 | 저장 상태를 프로젝트명 옆에 표시 | `저장 중 → 저장됨 · 시각 / 저장 실패 · 재시도`. 현재 자동 초안과 명시적 프로젝트 저장을 구분하고, 성공 전에는 완료로 표시하지 않는다. 로컬 스냅샷에는 이름과 시각을 붙여 비교/복원한다. |
| P1-1a | 기존 실행 취소/다시 실행을 상단에 노출 | 현재 `관리 ⋯` 안의 20단계 기능을 작곡기 공통 헤더에 꺼내고, 가능 여부와 마지막 작업명을 표시한다. 기록 중 잠금 규칙은 유지한다. |
| P1-2 | 녹음 대상과 저장 위치를 버튼 바로 위에 표시 | 예: `전체 믹스 → 보관함`, `목소리 베이스 → A파트`, `화음 2 → 성부 루프`. YouTube에서는 실제 정책·믹스 동작에 맞춰 `마이크만 녹음`을 표시한다. 모니터 꺼짐이 녹음 제외라는 뜻으로 보이지 않게 한다. |
| P1-3 | LCD를 작업 상태판으로 사용 | 기존 실제 미터와 피치를 유지하고, 작곡기 반주일 때 `A · 3/8마디 → 다음 B`, 예약 변경일 때 `다음 마디 적용`을 표시한다. 무음이나 정지에서는 장식용 미터를 움직이지 않는다. 장치 AEC의 활성/사용 불가/오류도 실제 상태를 사용한다. |
| P1-4 | S9 Ultra용 선택형 8트랙 믹서 | 같은 영역에서 `보컬 효과 / 트랙 믹서`를 전환한다. 각 트랙의 이름·생성/건반/목소리 구분·뮤트·임시 솔로·게인을 노출하고 세부 팬/패턴은 선택 후 연다. 채널별 실제 미터는 새 엔진 측정이 준비된 후 표시한다. 가짜 레벨은 사용하지 않는다. |
| P1-5 | 장치별 오디오 준비 안내 | 기존 입력/출력 선택·버퍼·싱크 검사·스피커 보호를 묶어 `입출력 확인 → 마이크 레벨 → 싱크 확인`으로 안내한다. 버퍼 추정값과 실측 지연을 구별한다. 경로가 바뀌면 보정값을 확인하며 마이크는 사용자 동작 없이 켜지지 않는다. Bluetooth 모니터 지연을 설정만으로 없앴다고 표시하지 않는다. |
| P2-1 | 화음 4성부를 2×2 타일로 정리 | 현재 상태와 카운트인/진행을 각 타일에 표시한다. 기존 녹음 취소·이전 성부 복원을 바로 접근하게 한다. 실제로 재녹음인 동작은 ‘겹쳐 녹음’으로 표시하지 않는다. 진정한 같은 성부 덧입히기는 별도 기능으로 설계한다. |
| P2-2 | 효과 프리셋과 A/B 비교 | 예: 자연스럽게/발라드/작은 방 등 소수의 프리셋과 현재 설정 비교. 적용 전 값을 보관하고 취소 시 되돌린다. 리버브·에코 두 값은 항상 메인에서 확인한다. 녹음 중 비교가 파일에도 반영되는지 먼저 명확히 정한다. |
| P2-3 | 반주를 ‘스타일·밀도·구간 대비’로 개선 | 기존 패턴/휴머나이즈/드럼 마지막 마디 필인을 먼저 평가하고, A/B 파트의 강약 대비와 연결을 묶어 제안한다. 고스트 노트·하이햇 변화·코드 연결 베이스·종지 필인의 부족한 부분을 청취로 골라 개선하고 전후를 비교한다. 모든 악기에 무작위를 더하는 방식은 피한다. 기존 시드 재현과 기록한 목소리의 정확한 타이밍은 유지한다. |
| P2-4 | 목소리 프레이즈의 테이크 선택 | 현재 재기록 취소/실행 취소를 유지하면서 두 테이크를 들어보고 채택한다. 원래 연주를 채택 전까지 보관하며 악기 교체·전조 시 두 테이크가 같은 규칙을 따른다. |
| P2-5 | 비활성 DSP의 절전 확대 | 이번에는 통계 조회의 노트 목록 복사를 없앴다. 후속으로 마이크가 꺼지고 잔향이 끝난 뒤 피치·화음·효과 경로를 잠들게 한다. 반주와 녹음 파일 쓰기는 계속되어야 하며 실제 CPU·오디오 끊김·온도/배터리를 전후 측정한다. 현재는 배터리 개선량을 실측하지 않았다. |
| P3 | 원음 보존 후 효과 재편집 / 직전 구간 복구 | 마른 입력과 믹스를 별도로 보존하는 파일·용량·중단 복구 설계가 필요하다. 직전 구간 버퍼도 사용자가 마이크를 켠 세션에만 명시적으로 허용한다. 기본 상시 녹음으로 만들지 않는다. |

## 태블릿 화면 제안

| 고정 위치 | 라이브 연주 보기 | 선택형 믹서 보기 |
|---|---|---|
| 상단 | 기존 앱명·3탭·출력 조작, 프로젝트명과 저장 상태 | 동일 |
| 왼쪽 LCD | IN/OUT·피치·시간·모니터·실제 입출력 상태, 현재/다음 파트 | 동일 |
| 오른쪽 위 | 반주 소스·재생 위치·독립 반주 음량 | 동일 |
| 오른쪽 본문 | 리버브/에코 두 노브와 상세 버튼 | 8트랙 채널, 선택한 트랙 상세 |
| 하단 | 녹음 대상·진행/실패 상태 + 고정 녹음/정지/영상 | 동일 |

폰에는 8개 채널을 억지로 축소하지 않고 선택 트랙과 목록을 사용한다. 화면 양 끝의 가로 스와이프를 필수 조작으로 만들지 않는다. 기존 파트 이동 화살표·시스템 뒤로가기·팝업 먼저 닫기 규칙을 유지한다. 한글/영어, 기본/130% 글씨, 짧은 분할 창에서 핵심 조작은 48dp 이상이어야 한다. 세부 설정은 스크롤 가능하되 저장/취소는 고정한다.

## 추천 구현 순서

**저장 상태 + 녹음 대상 + LCD의 파트 정보 → 태블릿 믹서 → 장치 설정 안내 → 화음 타일 → 반주 편곡과 테이크 비교 → DSP/원음 재편집.** 우선순위는 현재 코드와 사용자가 반복해서 제기한 편집·복구·배치·배터리 문제를 기준으로 판단했다. 다음 작업에서 대규모 화면 변경과 DSP 변경을 한 번에 섞지 않고 각각 검증할 것을 권한다.

직접 음표 편집과 프로젝트 WAV/MIDI 내보내기는 최초 합의 범위에서 제외되어 있으므로 이 제안의 기본 구현 범위에도 넣지 않았다. 기존 보컬 WAV/MIDI·영상 저장과 LLM JSON/ZIP 왕복은 유지한다.
