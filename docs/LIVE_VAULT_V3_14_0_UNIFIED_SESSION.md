# 3.14.0-preview — 통합 세션

작곡기 반주, 저장된 보컬 화음, 보컬 녹음을 하나의 프로젝트와 공유 타임라인에서 재생한다. 기존 작곡기 임시 작업과 보관함 테이크는 유지하며, 세션으로 가져올 때 별도 사본을 저장한다. 화면은 기존 매트 테마와 세 개의 기본 탭을 유지한다.

## 시작과 가져오기

1. 전체 메뉴의 **세션**을 연다. 보관함의 **세션** 필터에서도 현재 세션과 저장된 프로젝트를 연다.
2. **새 세션**에서 이름을 정한다. **열기**, **저장**으로 프로젝트를 관리하며 보관함에서는 이름 변경·복제·삭제가 가능하다.
3. **가져오기 → 현재 작곡기 복사**는 현재 악보를 세션에 복사한다. **현재 보컬 화음 복사**는 녹음된 성부와 해당 믹스 설정을 가져온다. 화음 녹음·준비가 끝난 뒤 가져온다.
4. **저장된 테이크**를 선택하면 오디오 소스를 다시 고른다. **보컬만**은 보컬 원음 보관 정보가 있는 테이크에서 제공한다. 원음 파일이 없거나 유효하지 않으면 가져오기를 실패로 알리며 원본 믹스로 조용히 대체하지 않는다. **원본 믹스 · 반주 포함 가능**은 원본에 반주가 포함된 경우 기존 작곡기·반주와 겹칠 수 있다는 확인 후 가져온다. 원본 자체가 보컬만 담고 있을 수도 있다.

오디오는 세션 소유 미디어로 복사하므로 가져오기 자체가 기존 테이크·화음 원본을 이동하거나 삭제하지 않는다. YouTube 모드에서는 세션 반주 가져오기·재생·녹음을 시작하지 않는다.

## 공유 시계와 보컬 녹음

프로젝트 위치·클립 시작·길이는 **48,000프레임/초**의 고정 시간축을 사용한다. 출력 장치가 44.1kHz로 동작하더라도 프로젝트의 1초는 48,000프레임이다. LCD에는 현재 시간·전체 길이·마디를 표시하며, 타임라인의 이름 열과 시간·마디 눈금으로 트랙 위치를 확인한다.

녹음할 위치에서 먼저 일시정지한다. 기존 트랙을 녹음 대상으로 선택하거나 **새 보컬 트랙에 녹음**을 누른다. **보컬 녹음**은 사용자가 마이크 권한을 허용한 뒤 명시적으로 시작하며, 녹음 중에는 **녹음 마침**으로 확정한다. 세션 반주는 들리지만 세션 녹음 파일에는 반주를 다시 합치지 않고 보컬을 저장한다. 저장된 보컬은 해당 위치의 클립으로 연결한다.

배치는 네이티브 입력 캡처의 시작 앵커와 녹음 시작 시 저장한 수동 오프셋을 사용한다. 수동 오프셋은 클립 위치에 한 번 적용하며, 같은 보정을 WAV에도 다시 적용하지 않는다. 음수 위치가 생기면 클립 시작을 0으로 두고 대응하는 소스 오프셋을 사용한다. 이는 사용자가 지정한 보정이며 실제 장치의 왕복 지연을 자동 측정한 값이 아니다.

## 편집과 기존 작곡기 보존

클립 시작 위치와 트랙 게인·팬·음소거는 세션을 일시정지하거나 정지한 상태에서 바꾼다. **클립 위치 이동**에서 한 마디 앞·뒤, 현재 재생 위치, 초 단위 시작 시간을 고른다. 같은 메뉴의 **클립 연결 삭제**, **트랙 옵션 → 트랙 연결 삭제**는 확인 후 연결 정보만 제거하며 저장된 오디오 원본은 유지한다.

**세션 작곡기 편집**은 기존 작곡기 임시 작업을 보관하고 해당 세션의 악보를 편집한다. 편집 결과는 연결된 세션에 저장하며, 편집 종료·세션 복귀 시 기존 임시 작업을 복원한다. 다른 세션을 열거나 복제하고 현재 세션을 삭제할 때도 이전 연결을 해제한다. 세션에 연결된 작곡기의 재생·정지는 공유 시계를 사용한다.

BPM·키 변경은 작곡기 반주에 적용된다. 이미 녹음된 오디오 클립은 원래 속도와 음정을 유지한다. 세션 작곡기 편집 중 목소리 악기·프레이즈 캡처는 지원하지 않으며 보컬은 세션 화면에서 녹음한다. 기존 독립 작곡기의 목소리·프레이즈 기능은 계속 사용할 수 있다.

## 누락 파일·미완료 녹음·종료

누락된 미디어는 클립의 문제로 표시하며 저장된 프로젝트를 버리지 않는다. 재생 준비에 실패하면 오류를 확인하고 해당 연결을 정리하거나 정상 원본을 다시 가져온다.

미완료 녹음 대상이 남아 있으면 **미완료 녹음 복구**를 표시한다. 저장된 테이크와 확인 가능한 위치가 있으면 사용자가 **이 세션 위치에 연결**을 선택한다. 시작 위치를 확인할 수 없는 녹음은 임의 위치에 자동 연결하지 않는다. 연결할 수 없거나 대상 정보를 버리려면 **연결 정보만 지우고 원본 보관**을 확인한다. 이 동작은 테이크 원본을 삭제하지 않으며, 미해결 대상이 있는 동안 새 녹음으로 덮어쓰지 않는다. 앱 재시작·장치 재연결·화면 열기만으로 마이크나 녹음을 자동 시작하지 않는다.

다른 반주를 재생하려면 세션을 먼저 정지한다. 종료 시 세션의 이미 수락한 편집과 진행 중 녹음 저장을 마무리한 뒤 서비스·오디오 자원을 정리한다. 저장 실패는 종료 확인에 전달하고, 복구용 대상과 원본을 성공한 것처럼 지우지 않는다.

## 범위와 검증 상태

최대 오디오 트랙 8개와 별도 작곡기 합성 반주, 클립 32개를 지원한다. 정밀 오디오 트리밍·타임 스트레치·녹음 오디오의 키 변환을 제공하는 DAW 편집기는 아니다. 재생 중 실시간 트랙 믹스 편집도 이번 범위에 포함하지 않는다.

[네이티브 검증 기록](validation/session-native-2026-11-10/README.md)은 호스트에서 실행한 엔진·캐시·콜백 검사 근거이며 Android 실기기 검증이 아니다. Android View 레이아웃 검사는 412×893 및 1480×924 창, 한국어·영어 130% 글꼴, 최대 트랙·클립·긴 이름을 사용한다. 화면 렌더와 자동 검사가 실제 Galaxy Tab S9 Ultra의 오디오 지연·USB 경로·마이크 녹음을 검증한 것으로 해석하지 않는다. 실기기 검증은 보류 상태다. 최종 단일 전체 실행에서 **62개 클래스·412개 Java/UI 검사**가 실패·오류·건너뜀 없이 통과했고 개인용 Android APK 빌드가 성공했다. 기존 패키지·서명 인증서가 일치하며 3개 ABI의 JNI 82개 내보내기와 Oboe·공유 STL 연결을 확인했다. 결과·렌더·수정 내역은 [최종 검증 기록](validation/v3.14.0/README.md)에 보존했다.
