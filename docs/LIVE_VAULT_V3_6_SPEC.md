# Live Vault 3.6 개인용 프리뷰 명세

**3.6.0-preview / versionCode 16**, personal 전용 체크포인트다. 공개 standard APK는 3.2.1-preview / versionCode 12를 유지한다.

기존 하단 탐색을 상단의 라이브·작곡기·보관함 버튼으로 옮겼다. 라이브에서 내 파일과 온라인 화면으로 바로 이동하고, 공용 효과 다이얼과 하단 녹음·영상 조작을 유지한다. 반주 음량은 파라미터 1로 파일·작곡기·기존 내부 반주에 적용한다. 외부 앱 소리의 음량은 운영체제와 해당 앱이 별도로 제어한다.

LCD는 실제 모니터 상태(stats 21)와 보호 음소거 상태를 표시한다. 입력과 출력을 각각 선택하고 저장하며 장치의 종류·제품명·ID를 구분한다. 소음 완화(p19)는 소프트웨어와 지원되는 하드웨어 노이즈 억제 설정에 반영되고 서비스 재시작에도 저장된 값을 사용한다.

마이크 없이 반주만 재생 중이어도 출력 변경을 적용한다. 녹음·예약·음성 프레이즈 및 화음 레이어 대기/녹음 중에는 경로 변경을 막는다. 경로 전환 실패 시 이전 선택을 복원하며, 출력 샘플레이트가 바뀌면 파일 재생 위치를 환산하고 모니터 상태를 복원한다. 경로 전환에는 짧은 스트림 재시작이 필요하다.
