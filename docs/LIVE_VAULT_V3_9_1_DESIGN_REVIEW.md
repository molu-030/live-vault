# Live Vault 3.9.1 — 노브 숫자 표시와 디자인 검수

`3.9.1-preview / versionCode 28`, 개인용 APK. 구현은 Sol medium, 디자인과 실제 화면 렌더 검수는 루트가 직접 수행했다. [3.9.0 태블릿 가로 배치](LIVE_VAULT_V3_9_0_TABLET.md)를 유지한다.

## 수정한 디자인

| 검수 항목 | 발견 사항 | 변경 |
|---|---|---|
| 태블릿 노브 숫자 영역 | 원형 면 위의 짙은 사각 배경과 밝은 테두리가 별도 창처럼 보임 | 배경·테두리를 제거하고 원형 면에 숫자와 단위를 직접 표시 |
| 큰 노브의 가독성 | 노브가 커져도 숫자가 15sp로 고정되어 상대적으로 작게 보임 | 노브 면 크기에 따라 15~34sp로 조정. 일반적인 `27%`는 한 줄에 표시 |
| 단위와 공간 | 숫자와 단위의 색이 갈리고 긴 값의 공간이 부족할 수 있음 | 숫자·단위를 같은 밝은 중립색으로 통일. 긴 값은 공간에 따라 두 줄로 배치 |
| 휴대폰 값 표시 | 작은 노브 아래에도 별도 색상 사각 배지가 있음 | 배지 배경을 제거하고 카드 위에 값을 직접 표시 |

효과 이름·위치 눈금·강조 호·숫자의 구분, 숫자와 위치 표시의 겹침, 한국어/영어, 글씨 100%/130%, 작은 휴대폰과 가로 태블릿의 잘림을 직접 렌더로 검수했다. 기본 태블릿·영어 130% 태블릿·960×600 창·360dp 큰 글씨의 최대값 표시에서 별도 배경이 사라지고 숫자가 읽히는 것을 확인했다. 기존 드래그 방향·값 범위·탭 설정창·뒤로가기 제스처·접근성 값을 바꾸지 않았다.

그림의 음높이·레벨·시간은 테스트 입력이다. Android View를 Skia로 실제 렌더한 화면이며 S9 Ultra 실기기 캡처가 아니다. 온라인 영상 렌더는 명시적인 오프라인 테스트 화면이다.
