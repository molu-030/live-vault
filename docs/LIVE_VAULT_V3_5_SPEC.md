# Live Vault 3.5 개인용 프리뷰 명세

**3.5.0-preview / versionCode 15**, personal 전용 체크포인트다. 공개 standard APK는 3.2.1-preview / versionCode 12를 유지한다.

라이브 콘솔은 무광 짙은 올리브·검정과 아이보리 직사각형 버튼을 사용한다. 여섯 값 버튼은 리버브, 잔향 길이, 목소리 크기, 에코 양, 간격, 반복 중 조절 대상을 선택한다. 중앙의 공용 다이얼 하나가 선택한 값만 바꾸며 접근성 및 키보드 조절을 제공한다. LCD에는 선택한 값과 실제 마이크, 출력·모니터, 녹음 시간, 반주, 입력 음 및 RMS 상태를 표시한다. 녹음·영상·설정 조작은 하단에 고정하고 지정된 작은 화면과 글자 크기에서도 라이브 본문을 스크롤 없이 배치한다. 영상 버튼은 카메라 미리보기를 연다.

반주 편집에는 오래된 편집기 및 프로젝트에 대한 롤백 방어, 8트랙 추가 전 검사, 재생·카운트인 취소 세대 관리, 프레이즈 롤백, 경계가 있는 note-on/off 처리와 파트별 믹스를 적용한다. 전용 솔로 해제는 믹서 값을 보존한다. 반주 LCD는 실제 재생 파트와 분할 코드를 표시한다. 즉시 음소거 오버라이드는 활성 중에만 적용하며, 다음 파트에서는 해당 파트의 믹스 게인을 사용한다.
