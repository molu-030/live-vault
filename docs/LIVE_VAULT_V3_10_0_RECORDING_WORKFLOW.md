# 3.10.0-preview / versionCode 33 — 녹음 후편집과 복구

## 구현 범위

- 새 녹음은 기존 최종 믹스와 함께 마이크 원음(float32 mono), 고정 믹스(float32 stereo)를 별도 보존한다. 마이크 원음은 **기기 AEC·소음 처리 이후, 앱 보컬 DSP 이전**이다. 디지털 반주는 보컬 효과를 우회하며 기존 녹음 버스를 유지한다.
- 보관함의 녹음 후 보컬 효과에서 리버브·에코·EQ·컴프레서·앱 소음 완화를 조절하고 원본 A/편집 B를 비교한다. 저장은 **새 WAV 복사본**으로 생성하며 원본을 덮어쓰지 않는다. 복사본에도 독립 소스를 보존해 원본 삭제 후 재편집할 수 있다. 취소·처리 실패 시 원본을 유지한다.
- 보관함에서 **직전 마이크 소리 10초 보관**을 명시적으로 켤 수 있다. 기본 OFF이고 앱 재실행 시 켜지지 않는다. 마이크를 자동으로 켜지 않으며 마이크 종료·기능 해제 시 버퍼를 비운다. 복구 파일과 메타데이터 저장에 성공해야 같은 세대의 버퍼를 비운다. 버퍼 복사 중 오디오 콜백은 기다리지 않고 보관만 잠시 건너뛴다.
- 녹음 싱크는 입력·출력 장치 쌍별로 저장한다. 실제 열린 스트림의 장치를 우선하며 재연결 때 바뀌는 런타임 ID는 키에 포함하지 않는다. 미확정 경로는 별도 프로필이다. 기존 출력별 싱크를 처음 상속하고 녹음 시작 시 불변 스냅샷을 보관하므로 녹음 중 라우팅 변경이 영상·오디오 메타데이터를 바꾸지 않는다. 화면에 보인 장치가 바뀌면 이전 슬라이더 저장을 거부한다.
- 작곡기 프로젝트 버전은 프로젝트별로 최대 20개를 디스크에 보관한다. 이름 변경·차이 미리보기·복원·복사본 생성이 가능하다. 복원 전 현재 상태를 자동 백업하고 실패·취소·편집 충돌 때 기존 버전을 보존한다. 프로젝트 삭제 시 그 프로젝트의 버전도 삭제한다.
- 보컬 DSP는 잔향이 충분히 사라진 후 제한된 분할 검사로 휴면 전환한다. 콜백에서 전체 지연 버퍼를 한 번에 훑거나 지우지 않는다. 512프레임당 최대 256슬롯 검사이며 새 입력·설정 변경 시 원래 처리 경로를 유지한다.

## 사용 시 구분할 사항

- 기존 녹음에는 원음이 없으므로 후편집을 소급 제공하지 않는다. 라이브 화음/일부 목소리 악기 라우팅은 기본 보컬 DSP만으로 재현할 수 없어 후편집을 제한하고 이유를 표시한다. 원음과 최종 녹음은 유지한다.
- 후편집은 기본 보컬 효과를 전체에 일정하게 적용한다. 녹음 중 효과 자동화, 이미 처리된 화음/루프, 기기 AEC로 제거된 소리를 되돌리지 않는다. 일시정지 구간은 제외되고 효과 꼬리는 다시 계산한다. 비교는 다른 앱 내 반주를 일시정지하며 자동 재개하지 않는다.
- 영상 원본은 유지하며 후편집 결과는 WAV 오디오 사본이다. 프로젝트 MIDI/WAV 내보내기나 직접 음표 편집을 추가한 변경이 아니다.
- 추가 소스 저장 비용은 48 kHz에서 약 **35 MB/분**이다. 저장 공간/소스 쓰기 실패 시 최종 녹음을 우선 보존하고 불완전한 소스로 편집 가능하다고 표시하지 않는다.
- 10초 복구는 **마이크 소리** 대상이다. 디지털 반주/YouTube를 직접 합치지 않지만 스피커에서 마이크로 다시 들어온 소리는 포함될 수 있다. 역상 출력을 내는 것만으로 방의 반사를 제거할 수 없으며 기존 AEC·단계적 하울링 보호를 유지한다.
- 긴 에코 피드백의 휴면 진입은 약 197초까지 걸릴 수 있다. 호스트 CPU 결과를 태블릿 배터리 절감률이나 실시간 마감 보장으로 해석하지 않는다.

## 검증 및 전달

실제 엔진을 사용하는 44.1/48 kHz ASAN/UBSAN 검사로 원음/고정 믹스, 오프라인 렌더, 싱크·일시정지·실패, 최근 소리 버퍼와 디지털 반주 효과 격리를 확인했다. DSP 휴면 검사는 잔향·재입력·EQ 재초기화·검사 상한을 확인하며 최대 샘플 오차는 2.72e-19이다. 전체 Java/UI 검사 **304개 통과(실패·오류·건너뜀 0)**, 개인용 APK 빌드 및 3개 ABI 신규 JNI 심볼/기존 서명을 확인했다. 검사 결과와 개인용 APK 해시는 `validation/v3.10.0/`에 기록한다.

연결된 실기기가 없어 **S9 Ultra 실제 음향·장치 재연결·지연·배터리·장시간 녹화는 미검증**이다. 개인용 APK만 기존 앱 ID/인증서로 빌드한다. 공개 일반용 APK와 개인용 캡처 소스·서명키는 배포 커밋에 포함하지 않는다.
